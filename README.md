# SharikiHub - منصة شاركني هاب

منصة شاملة تجمع بين التواصل الاجتماعي، الترفيه، وخدمات الطباعة حسب الطلب (Print on Demand).

## 🚀 أقسام المنصة ومكوناتها

- **الرئيسية (`index.html`):** الواجهة الرئيسية لاستكشاف المنصة والوصول لكافة الخيارات.
- **استوديو التصميم (`design-studio.html`):** أداة تفاعلية تخصّص المنتجات (تيشرتات، أكواب، أغلفة) وتسمح للمستخدم برفع التصاميم والنصوص.
- **الترفيه (`entertainment.html`):** قسم متكامل يغطي مجالات (الكتب، الرياضة، الأزياء، والأفلام).
- **المقاطع القصيرة (`reels.html`):** منصة لعرض مقاطع الفيديو التفاعلية.
- **لوحة التحكم (`admin.html`):** لإدارة المنتجات، الطلبات، والترتيب العام للموقع.
- **من نحن (`about.html`) & الخصوصية (`privacy.html`):** التعريف بالمنصة وسياستها لبناء الثقة مع المستخدِمين.

## 🛠️ التقنيات المستخدمة

- **HTML5 / CSS3 / JavaScript** لبناء الواجهات والتفاعل المباشر.
- **GitHub & GitHub Pages** للاستضافة وإدارة المستودع.
